# GEDY AI Assistant

This is an AI-powered desktop assistant designed to help perform tasks on the computer using natural language.

The project started with a simple idea: instead of manually opening applications and performing small tasks, I wanted to be able to tell my computer what I wanted it to do and have my AI assistant handle it for me.

### What It Can Do

For now, the assistant can perform basic computer tasks, including opening applications such as:

* Notepad
* File Explorer
* YouTube
* And other applications installed on the computer

Right now, I’m building the assistant with the goal of gradually expanding its capabilities and making it more useful for everyday computer interaction.

### Planned Features

As development continues, I plan to add features such as:

*  Search for information on the web
*  Send text messages
*  Make phone calls
*  Take screenshots
*  Understand what is currently displayed on the screen
*  Analyze coding errors and suggest fixes
*  Perform more complex tasks across the computer

### Why I Built It

One of the reasons I wanted to build this assistant comes from a simple problem I personally experience.

Sometimes, while I'm working on something on my laptop, I suddenly remember that I need to send someone a message. I might think, *"I'll do it when I'm finished with this."* Then I finish what I'm doing and completely forget about the message.

With this assistant, I want to be able to simply call it and say something like:

> "Send a message to John telling him I'll call him later."

Instead of interrupting what I'm currently doing, I can give the instruction immediately and let the assistant handle it.

Another feature I want to add is screenshot-based debugging.

As a developer, when I run into an error, I often need to stop what I'm doing, inspect the terminal, copy the error, and then search for a solution. My goal is to make this process much simpler. I want to be able to maximize my terminal, ask the assistant to take a screenshot, and have it analyze the error, explain what's wrong, and suggest a fix.

### The Goal

Ultimately, I want this project to become more than an AI chatbot. I want it to become an assistant that can actually **interact with my computer and help me get things done**.

The project is still in development, and I'm building new capabilities as I go.
